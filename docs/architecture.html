CAD-to-Cutlist Engine — System Architecture

3D furniture model → extracted boards → nested sheets → CNC-ready DXF / G-code / cutlist artifacts
1 · Inputs

CAD / 3D Exports

OBJ · STL (bin + ASCII) · DAE · DXF (3DFACE / MESH / POLYFACE, ezdxf) · JSON triangle mesh

SketchUp Plugin

sketchup_plugin/cutlist_engine_loader.rb — Extensions-menu loader: exports active selection to OBJ (mm), launches CLI

Configuration

overrides_example.json (grain / priority / edge band / material / label) · materials_example.json (thickness, sheet size, cost) · review_example.json (accept / reject / rename)

2 · Interfaces

CLI — cli.py

cutlist-engine input.obj --output-dir out
kerf, grain-locked, sheet-cost, candidate sizes, G-code tunables, --force gate override

FastAPI Server — server.py

POST /api/extract → session + boards
POST /api/finalize/{id} → all artifacts
GET /api/download/{id}/{file}
/api/ai/label · /api/ai/describe · /api/ai/chat
/healthz

React / Vite Frontend — frontend/

Operator review SPA: upload → inspect each board (polygon thumb, confidence, warnings) → accept / reject / rename → one-click generate. Chat drawer for AI assistant.

3 · Core Engine Pipeline (src/cutlist_engine)
parsers.py
triangle stream
geometry.py
plane clusters · contours · holes
boards.py
pair planes → boards · dedup · confidence
Quality Gate
min-confidence — refuses bad cutlist
pipeline.py
overrides · edge band · materials · review · cost
nesting.py
MaxRects · kerf · grain · priority · cut order
4 · AI Services (optional, Groq)

ai.py — Groq Llama-4 Scout

label_parts() — auto-name boards in Indian shop-floor terminology
describe_to_cutlist() — natural language → structured cutlist
chat() — context-aware workshop assistant

5 · Outputs (outputs.py · dxf_export.py · gcode_export.py)

report.json

extraction, waste, sheets, strategy, model-fix, per-material data

cutlist.csv

material, finished + cut size, edge band, grain

sheet_layout.html

visual cutting plan, metrics, alerts, sheet comparison

labels.html

printable A4 cards (2-up), grain arrow + edge band

dxf/sheet_NN.dxf

layered DXF: SHEET · PART · PART_FINISH · OFFCUT · LABEL · GRAIN

gcode/sheet_NN.nc

kerf-compensated RS-274, multi-pass plunge — GRBL / Mach3 / LinuxCNC / Fanuc / Haas

6 · Runtime & Production Controls (env vars)

Sessions

CUTLIST_SESSION_DIR (persisted review sessions, TTL via CUTLIST_SESSION_TTL_HOURS)

Security

CUTLIST_API_TOKEN — Bearer auth on /api/* when set

Limits

CUTLIST_MAX_UPLOAD_MB (100) · CUTLIST_MAX_TRIANGLES (500k)
